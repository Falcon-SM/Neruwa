# ねるわ iOS / Android

「夜に睡眠を記録し、朝の状態と一緒に振り返る」ための SwiftUI アプリです。Web PoC の中心フローを引き継ぎつつ、Apple純正アプリと同じナビゲーション、リスト、フォームを使い、時刻だけで切り替わる軽量な空の背景を組み合わせています。

Android版は [`Android`](Android) にあります。Jetpack ComposeとMaterial 3で同じ5タブ、時間帯別の朝・夜フロー、睡眠タイマー、学習カードとCSV、90秒PVT、気分色付きカレンダー、共有フィードを実装しています。Android版の3DねるるんはSceneView（Filament）でGLBを直接読み込み、状態に合わせて殻ごと揺れます。アプリアイコンと各問いかけにも同じモデルのレンダーを使用します。

Android Studioで `Android` ディレクトリを開くか、JDK 17とAndroid SDK 36を用意して次を実行します。

```bash
cd Android
./gradlew :app:assembleDebug
```

生成物は `Android/app/build/outputs/apk/debug/app-debug.apk` です。GitHub Actionsの `Android build` でも同じデバッグAPKを検証・保存します。

## プロダクト方針

対象は、寝ようと思えば寝られる環境にいながら、SNS・動画・ゲームを目的なく続けて夜更かししてしまう大学生です。卒論直前や業務都合など、本人の意思だけでは睡眠時間を確保できない状況は主な対象にしません。

無限スクロールには小さな操作で得られる即時報酬と明確な終わりのなさがある一方、睡眠の効果は翌朝まで見えにくく、昨日の夜更かしと今日の不調も結びつけにくいという課題があります。本アプリは睡眠の重要性を説くだけでなく、次の仕組みで「寝る」行動を選びやすくします。

- 就寝前の日記と明日の3項目で一日に区切りをつける
- 睡眠学習と翌朝の確認テストで、就寝と学習成果を近づける
- 睡眠時間・気分・テスト結果を振り返り、行動と翌日の状態を結びつける
- 共有をソーシャルナッジとして使い、継続するきっかけを作る

現在のMVPは、記録・日記・点字学習・朝のテスト・気分記録と、短い睡眠ログをアプリ内で共有するフィードに絞っています。TMT、キャラクター報酬などは下記ロードマップの項目であり、現在の実装には含まれません。

## MVP の範囲

- 夜の必須フロー専用の睡眠タイマー（開始日時を保存し、アプリ再起動後も「起床して記録」画面を復元）
- 通常の「睡眠記録」タブから行う就寝・起床日時の手入力
- 目標睡眠時間
- 朝の気分 4 段階とコメント、睡眠時間のアナログ時計表示
- 各日に睡眠時間と気分色を表示する月間カレンダー、日付タップで開く睡眠詳細と7日間チャート
- HealthKit から昨晩の睡眠と、選択日の「心の状態」を読み込み
- ローカル優先保存と、ログイン時の Firestore 同期
- Google / Firebase ログインとローカルのゲストモード
- 「今日・手放す・明日の3つ」で構成する就寝前の日記
- 通常タブでの点字・英単語などの学習と、必須フロー内の睡眠音声設定・睡眠セッション単位の朝テスト
- 自作カードのフォルダ分けとCSV一括インポート（UTF-8 / Shift_JIS、日本語・英語読み上げ）
- 合図への反応時間、500ms以上の遅延、フライングを90秒間測る簡易PVTと、1日・1週間・1ヶ月の比較グラフ
- 3Dモデル「ねるるん」の正面レンダーを、アプリアイコンと朝・夜・学習・PVTの問いかけに統一して使用
- 学習カード・再生設定・テスト結果のアカウント別ローカル保存
- 「みんなの睡眠」と分離した投稿画面から、最新の睡眠時間・目標達成率・任意の気分・短文を投稿
- 投稿ごとの公開範囲は「みんな」または「この端末のみ」から選択し、既定値を設定で変更
- 匿名表示名のタイムラインと「おやすみ」リアクション（ゲスト・オフライン時はローカル表示）
- 必要な場合に限り、同じ睡眠サマリーをiOS共有シートで外部共有
- 初期値19:00〜翌04:59の静的な星空と、それ以外の時間帯の静的な朝・昼の空背景
- 朝と夜の開始時刻を設定から変更し、必須フローと背景へ同じ判定を適用

TMTは現在のiOS版には含めず、朝の流れではスキップします。共有フィードは認証済みユーザーで検証するMVPです。招待した友達だけに公開する仕組み、ブロック、通報、友達単位の公開範囲は本番公開前に追加します。

## 1日の流れ

```text
夜: 今日を閉じる → 点字を学ぶ → 睡眠音声 → 睡眠を記録
朝: 今朝の気分 → PVT → 朝の点字テスト → 記録・分析
```

アプリを開いた時刻に応じて、その対象日でまだ完了していない流れを全画面で表示します。「あとで」で途中中断でき、次回は保存済みの同じステップから再開します。睡眠タイマーの計測中だけは誤操作で計測画面を失わないよう中断できません。一度完了した後は通常のタブUIを自由に使えます。進捗はFirebase UIDまたはゲストプロフィールごとに端末へ保存します。

Homeタブは設けず、未完了の朝・夜フローを通常タブより先に全画面表示します。夜は睡眠記録を終了するまで同じフローを維持し、「起床して記録」から朝フローへ直接つなぎます。朝フロー完了後は月間カレンダーの「記録」を最初に表示します。

- 初期設定19:00〜翌04:59: `日記 → 点字学習 → 音声設定 → 睡眠記録`を必須表示し、星空の背景にする
- 初期設定05:00〜18:59: `気分 → PVT → 点字テスト → 記録`を必須表示し、朝・昼の空背景にする

朝のPVTと確認テストは、それぞれ開始前または実行途中にスキップできます。スキップ状態は日次進捗へ保存されるため、次回起動時に同じテストへ戻りません。PVTは90秒間繰り返し反応を測り、平均・最速・500ms以上の遅延・フライングと、試行ごとの反応時間グラフを端末へ保存・表示します。通常のPVTタブでは、当日の複数結果、過去1週間、過去1ヶ月を切り替え、期間内の実施回数と日ごとの平均推移を比較できます。医療診断や運転可否の判断には使用できません。学習カードが2枚未満でテストを構成できない場合は、理由を表示して記録へ進めます。夜の睡眠タイマーを開始すると、設定した朝の開始時刻を過ぎたりアプリを再起動したりしても、全画面の計測画面を維持します。「起床して記録」を押した時点で初めて睡眠を保存し、その記録を対象とする `気分 → PVT → 点字テスト → 記録` の朝フローへ直接つなぎます。睡眠セッションがない初回利用でも気分とテスト結果を日次進捗へ保持し、同じ起床日の記録が後から追加された時点で自動的に結び付けるため、行き止まりにはなりません。通常タブの「睡眠記録」は手入力専用で、タイマーは夜の必須フローに集約しています。

朝と夜の開始時刻は設定の時刻ピッカーで変更できます。2つの時刻が同じ場合や保存値が不正な場合は、安全のため初期値の05:00 / 19:00へ戻します。朝・夜のどちらの区間が0時をまたいでも、その区間が始まった日を基準に1回だけ実行します。通常の「学習」タブは学ぶ画面だけを表示し、音声設定と朝テストは必要な時間帯の必須フローから開きます。

デモ時は、設定の「デモ」から「朝を今すぐ始める」「夜を今すぐ始める」を選ぶと、設定時刻や当日の完了状態に関係なく各フローを最初から確認できます。デモ進捗は通常の日次進捗とは別IDで保存するため、本来の朝・夜フローの完了状態を上書きしません。

背景の判定には端末の現在時刻だけを使います。位置情報、天気サービス、ネットワーク通信は使用しません。

## 起動

1. `Sleeper.xcodeproj` を Xcode で開く。
2. Signing & Capabilities で自分の Team を確認する。
3. Google ログインを使う場合は、Firebase に登録した Bundle ID と `GoogleService-Info.plist` を一致させる。
4. HealthKit の動作確認は、睡眠または「心の状態」のデータがある実機で行う。
5. `Sleeper` scheme を実行する。

Firebase を設定していない環境でも「ゲストとして試す」からローカル機能を確認できます。

睡眠学習では、Web PoC の大容量音声ファイルをコピーせず、iOS の日本語音声合成を利用します。通常の「学習」タブではカードを学び、夜の必須フローで間隔・時間・音量を設定します。睡眠タイマーとの自動連携を有効にすると、計測開始・終了に合わせて再生を制御します。長時間のポーリングは行わず、端末負荷を抑えるため1回の再生キューは最大120発話です。

CSVは1行目を `prompt,answer,speech,language,folder,braille` とする形式を推奨します。`問題,答え,読み上げ,言語,フォルダ,点字` や `front,back` などの見出し、UTF-8 BOM、カンマ・タブ・セミコロン区切りにも対応します。見出しなしの場合は同じ列順として扱います。英単語では `language` を `en` または `en-US` にでき、省略時も読み上げ文字が英字だけなら英語音声を選びます。`speech`、`folder`、`braille` は省略でき、フォルダ未指定時はCSVファイル名でまとめます。点字の点番号は `1・2・4`、複数マスは `1・2/1・5` のように記述できます。引用符内のカンマ、改行、`""` による引用符のエスケープにも対応します。

睡眠記録画面では3Dキャラクター「ねるるん」を表示します。提供された `Nerurun.glb` の全3,051,283頂点・全1,020,884ポリゴンと、肌・くちばし・目・殻・葉の5マテリアルを保持したUSDZをアプリに同梱し、卵の殻ごと常にゆっくり揺れます。直近の睡眠時間、目標達成率、朝の気分、7日間の記録頻度から「正常」「ちょっとしょんぼり」「疲れ限界」「とてもいいペース」を端末内で判定します。しょんぼり時はクローバー、疲労時は目のクマを表示し、好調時は継続日数に応じて子どものひよこが腹元に最大3羽まで増えます。アプリアイコンと各フロー内の2D表示にも、同じ3Dモデルから生成した画像を使用します。

## UI 方針

- 画面上の情報は `List`、`Form`、`Section`、`LabeledContent` で整理
- タブバー、ナビゲーション、標準ボタンの Liquid Glass はOSに任せ、コンテンツ面へ独自のGlassを重ねない
- 標準List/Formの背後に、設定した夜の時間は星空、それ以外は時刻に合わせた朝・昼の静的背景を1枚だけ表示
- 睡眠時間は時計と同じアナログ表示、履歴は日付・睡眠時間・気分色を一度に確認できるコンパクトな月間グリッドで構成
- SF Symbols、Dynamic Type、標準スワイプ操作を利用し、ヘルスケアや時計と同じ操作感を優先
- iPhoneでは「睡眠記録・学習・PVT・記録・共有」の5タブ、広い画面ではシステムのサイドバーへ適応

## 軽量化

- 長い履歴とカード一覧はシステムの `List` で必要な行だけ生成
- 独自のGlassとぼかしをコンテンツから除去し、背景Canvasは選択中のタブにだけ1枚表示して常時アニメーションしない
- 睡眠時計の1秒更新は、計測中かつ画面が表示され、アプリが前面にある間だけ実行
- 各画面の縦スクロールをシステムのコンテナ1つに統一
- 時計、学習カード、日記入力欄の高さと余白を抑え、主要な次操作は画面下へ固定
- Firestore同期は取得済みスナップショットとの差分だけを最大400件ずつ書き込み
- 全睡眠記録の削除はローカル保存を1回だけ更新し、クラウド側も最大400件のバッチで反映
- 未使用だった `GoogleSignInSwift` 製品のリンクを削除

CLI で確認する場合、Command Line Tools ではなく Xcode 本体を指定します。

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
  xcodebuild -project Sleeper.xcodeproj \
  -scheme Sleeper -destination 'generic/platform=iOS' \
  CODE_SIGNING_ALLOWED=NO build
```

## データ設計

Web PoC の「日付ごとに 1 件」ではなく、複数セッションと夜跨ぎを扱える `SleepSession` を使います。手入力・タイマー・HealthKitで同じ時間帯の記録が入った場合は、HealthKitの睡眠段階と既存の気分・メモを保ちながら1件へ統合します。既存データに重複が残っていても、カレンダー・分析・朝フロー・共有では解決済みの記録だけを使うため睡眠時間を二重加算しません。

```text
SleepSession
├─ id
├─ startDate / endDate
├─ targetMinutes
├─ source: timer / manual / healthKit
├─ mood / note
├─ sleep stages（HealthKit の場合）
└─ createdAt / updatedAt
```

ローカルを先に更新し、ゲストと各 Firebase UID の保存領域を端末内でも分離します。認証済みユーザーだけ次の Firestore パスへ同期します。

```text
/users/{uid}/sleepSessions/{sessionId}
```

アプリ内共有では、個人の睡眠記録とは分離した次のパスを使います。

```text
/sleepFeedPosts/{postId}
/sleepFeedPosts/{postId}/sleepFeedReactions/{uid}
/sleepFeedPostOwners/{postId}
```

公開投稿には匿名表示名、起床日、睡眠時間、目標達成率、任意の気分、80文字以内の投稿文だけを持たせます。所有者UIDは本人だけが読める別ドキュメントへ分離します。「この端末のみ」を選んだ投稿はFirestoreへ送信しません。正確な就寝・起床時刻、睡眠ステージ、HealthKit識別情報、夜の日記、朝の振り返り本文は公開投稿にフィールド自体を用意していません。

睡眠学習データは現在端末内に保存し、ゲストと各 Firebase UID の領域を分離しています。学習内容を意図せずクラウドへ送らず、共有フィードにも学習カードやテスト内容は含めません。

PVT結果もプロフィール別に端末内へ保存し、朝フローから実行した結果には対象の睡眠セッションIDを関連付けます。PVTの反応時間は共有フィードへ送信しません。

リポジトリ直下の `firestore.rules` に、本人限定の睡眠記録、投稿フィールドの検証、本人単位のリアクション更新を定義しています。`firestore.indexes.json` にはリアクション状態をまとめて取得するコレクショングループ索引を定義しています。ルールと索引をFirebaseへデプロイするまでは、クラウド投稿に失敗してもローカルフィードへ記録を保持します。

```bash
firebase deploy --only firestore --project YOUR_FIREBASE_PROJECT_ID
```

## プライバシー

- HealthKit は睡眠分析と「心の状態」の読み取りだけを要求し、書き込みません。「心の状態」は選択日の表示にだけ使い、ねるねの気分記録を上書きしたり共有フィードへ送ったりしません。
- 背景の切り替えには端末の現在時刻だけを使い、位置情報や天気データは取得しません。
- アプリ内投稿には正確な就寝・起床時刻、睡眠ステージ、HealthKit識別情報、日記、振り返り本文を含めません。気分も初期状態では共有しません。
- 夜の日記はプロフィール別に端末内へ保存し、設定からそのプロフィール分だけを全削除できます。
- `PrivacyInfo.xcprivacy` で、アプリ内だけの設定・ローカル記録に使う `UserDefaults` のRequired Reason APIを宣言しています。
- HealthKit 由来データを Firestore へ同期する場合は、利用目的と削除方法を公開前に明示してください。
- Web PoC の動画・音声にはライセンス表記がないため、このアプリにはコピーしていません。
- 睡眠中の読み上げを画面ロック後も継続するため、Background Modes の Audio を使用します。音量を小さくして短時間から試してください。
- 配布前に Sign in with Apple の要否、Firestore Rules、アカウント削除、データ export / delete を確認してください。

## Web PoC からの移植方針

再利用するのは画面フロー、色、記録項目、集計ロジックです。Next.js、Local Storage、Web Notification、HTML Audio のコードは SwiftUI、ローカル永続化、UserNotifications、AVFoundation へ段階的に書き直します。
